# 대표이사 낙마 사례 카탈로그 (약 30년) → 우리 리스크 카테고리

목적: 리스크 taxonomy를 *선험적 컴플라이언스 체크리스트*가 아니라 **실제로 CEO를 날린 사건**으로 근거화한다. 코드의 `selfdeploy/categories.py`(`RISK_CATEGORIES`)와 의무 템플릿(`templates.py`)이 이 카탈로그의 구현이다. `selfdeploy categories`로 조회.

> **핵심 발견:** 우리의 초기 모델은 제조·안전·법규엔 강했지만, **한국 CEO를 실제로 가장 많이 날린 축 — 오너·임원 품행(갑질·비위), 파트너(대리점·가맹점) 갑질, 소비자 기만 —** 은 아예 없었다. 이 카탈로그가 그 갭을 드러냈고, 4개 신규 의무(exec_conduct / consumer_honesty / partner_fairness / workplace_culture)와 새 노출 클래스 `윤리·품행`을 추가했다.

## 카테고리 × 사례

### C1. 안전·품질 재해·리콜 — 노출: 안전·생명/법규/브랜드·여론
- **보잉 737 MAX** 도어플러그 이탈(2024) → CEO Dave Calhoun 사임, 상용기부문장 즉시 사퇴.
- **펠로톤** 트레드밀 아동 사망·부상 70여건, 리콜 지연(2021) → CEO John Foley 사과·교체.
- → 커버: `product_liability`, `consumer_safety`, `worker_safety`

### C2. 금융·회계 부정·횡령·자금세탁 — 노출: 법규/재무/브랜드·여론
- **닛산 카를로스 곤** 보상 미신고·회사자산 사적사용(2018) → 축출·기소.
- **단스케방크** 유럽 최대급 자금세탁(2018) → CEO Thomas Borgen 사임.
- **대표이사 횡령**(상시, 한국 다수) → 기업 존립 위협·대표 형사.
- → 커버: `financial_control` (자금승인·대사·실사; 횡령·세탁 탐지는 향후 강화 대상)

### C3. 소비자 기만·영업 부정 — 노출: 법규/브랜드·여론/재무
- **웰스파고** 유령계좌 200만 건(무리한 할당 압박)(2016) → CEO John Stumpf 사임, CFPB $185M.
- **남양유업 불가리스** 코로나 억제 효과 허위 발표(2021) → 홍원식 회장 사퇴·지분 매각.
- → 커버(신규): `consumer_honesty` (표시·광고 근거검증 / 판매동의 진정성 / 할당압박 통제)

### C4. 오너·임원 개인 품행(갑질·비위) — 노출: 윤리·품행/브랜드·여론/법규/노무·ESG  ★한국 CEO 낙마 최대 원인
- **대한항공 땅콩회항**(2014) 조현아 부사장 → 임원직 사퇴.
- **한화 김승연** 아들 관련 보복폭행(2007) → 회장 유죄.
- **미스터피자 정우현** 갑질(2017) → 회장 경영 퇴진·유죄.
- **맥도날드 Easterbrook** 직원과 부적절 관계, 사규 위반(2019) → CEO 해임.
- **올림푸스 Kaufmann** 불법 약물(2024) → CEO 사임.
- **WWE McMahon** 성비위 무마금 $19M(2022) → CEO 사임.
- → 커버(신규): `exec_conduct` (행동강령 서약 / 비위 핫라인 / 갑질 모니터링 / 이해상충 공시)

### C5. 파트너·협력사 갑질(대리점·가맹점) — 노출: 법규/브랜드·여론/노무·ESG  ★매우 한국적
- **남양유업 대리점 밀어내기(강매)**(2013) → 불매 10년, 2021 오너 경영 종료·매각. '남양유업방지법'(대리점법, 2016) 제정 계기.
- **미스터피자 가맹점 갑질**(2017) → 회장 퇴진.
- → 커버(신규): `partner_fairness` (밀어내기 금지 / 협력사 분쟁처리 / 계약 공정성)

### C6. 노무·조직문화·성비위 — 노출: 노무·ESG/윤리·품행/브랜드·여론/법규
- **우버 Kalanick** 독성 조직문화·성희롱 대응 실패(2017) → CEO 사임.
- **WWE** 성비위(2022) → 사임.
- → 커버: `workplace_culture`(신규: 괴롭힘·성희롱 신고 / 문화진단 / 무마금 투명성) + `labor_safety`

### C7. 홍보·마케팅 정서 충돌 — 노출: 역사·사회/브랜드·여론/정치
- **스타벅스 탱크데이**(2026) '탱크데이/책상에 탁'이 5·18·박종철 연상, 5·18일 진행 → 손정현 대표 해임, 대국민 사과, 불매, 매출·앱 급감, 5·18특별법 위반 고발.
- → 커버: `brand_sensitivity` + 사전 `sensitivity-check`/`clear-action` 게이트

### C8. 규제·컴플라이언스(환경·개인정보·공정거래) — 노출: 법규/브랜드·여론
- 환경(화관법·물환경보전법), 개인정보(개인정보보호법), 공정거래 위반 → 과징금·대표 문책.
- → 커버: `environment`, `privacy`, `financial_control`

## 이 조사가 우리 모델에 남긴 것

1. **새 노출 클래스 `윤리·품행`** (가중치 0.9) — 갑질·비위가 한국 CEO를 날리는 축.
2. **4개 신규 의무** (모든 소비자 브랜드 업종에 적용): `exec_conduct`, `consumer_honesty`, `partner_fairness`, `workplace_culture`.
3. **패턴 확인:** CEO 낙마의 무게중심은 *제조 안전*이 아니라 *사람(오너·임원·조직) + 대외 정서*에 있다. 법규 뷰가 가장 못 보는 영역이고, 정확히 우리 노출 축이 잡는 영역이다.

## 남은 갭 (다음)
- **横령·자금세탁 탐지**(C2)는 통제 기록만으론 약함 — 이상거래 탐지 신호 필요.
- **오너 품행(C4)**은 사내 시스템에 안 남음 — 외부 신호(미디어·SNS·제보) 수집기 필요(비법규 노출과 동일 과제).
- 국가·업종별 사례 확충(현재 한국 중심 + 글로벌 일부).
